
# Amazon Sales Data Analysis | Power BI

## Project Overview
An interactive data analytics project using Microsoft Power BI to explore and visualise Amazon sales data.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Visualisation
- Data Analysis

## Project Objectives
- Explore the Amazon sales dataset.
- Identify meaningful patterns and trends.
- Present data through interactive visualisations.
- Generate insights to support data-driven decision-making.
